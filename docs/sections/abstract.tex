This project addresses the resolution of three logic puzzles --- \textbf{Mosaic} (difficulty 1), \textbf{Range} (difficulty 5), and \textbf{Galaxies} (difficulty 9) --- sourced from Simon Tatham's Portable Puzzle Collection. For each puzzle, we derive an Integer Linear Programme (ILP), implement it in Julia using JuMP and CPLEX, design a random instance generator, and develop a complementary heuristic solver. For Range, two connectivity enforcement strategies are compared: a classical single-commodity flow formulation and a dynamic approach based on CPLEX lazy-constraint callbacks, with the callback approach yielding consistent 2--6$\times$ speed improvements. Galaxies, as the most complex puzzle, relies entirely on lazy-constraint callbacks to enforce region connectivity under the rotational symmetry constraint. Both CPLEX solvers find optimal solutions reliably across all tested instance sizes for Mosaic and Range; Galaxies experimental results are pending.
