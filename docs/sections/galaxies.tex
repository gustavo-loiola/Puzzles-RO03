\section{Galaxies}
\label{sec:galaxies}

\subsection{Puzzle Description}

Galaxies is played on an $n \times m$ grid containing a set of dots called \emph{galaxy centres}. The goal is to partition every cell of the grid into connected regions such that:
\begin{enumerate}
  \item \textbf{One centre per region:} each region contains exactly one dot.
  \item \textbf{180° rotational symmetry:} every region must be rotationally symmetric about its dot (i.e., for every cell $(i,j)$ in region $k$ with centre $(c_r^k, c_c^k)$, the cell $(2c_r^k - i,\; 2c_c^k - j)$ must also belong to region $k$).
  \item \textbf{Connected regions:} each region must form a 4-connected set of cells.
  \item \textbf{Full partition:} every cell belongs to exactly one region.
\end{enumerate}

Galaxy centres can lie on cell centres, on edge midpoints, or on vertex intersections of the grid, making the symmetry axis non-integer in general. This puzzle is rated difficulty 9, the highest in the project, because the connectivity constraint (Rule 4) for each region cannot be encoded with a polynomial number of linear inequalities upfront.

\subsection{ILP Formulation}
 
The objective is pure feasibility: any assignment satisfying all constraints is a valid solution. We therefore use a constant objective of $0$, or alternatively minimize a perimeter cost to bias CPLEX toward compact galaxies and break ties faster.

\subsubsection{Sets and Decision Variables}

We use a \emph{double-grid} coordinate system: the centre of cell $(i,j)$ is placed at double-grid point $(2i-1,\, 2j-1)$, so coordinates range over $\{1,\ldots,2n-1\}\times\{1,\ldots,2m-1\}$. A dot at double-grid position $(d_r^k, d_c^k)$ may sit at a cell centre (both odd), a horizontal edge (even row, odd column), a vertical edge (odd row, even column), or a grid corner (both even), touching 1, 2, 2, or 4 cells respectively.

\subsubsection{Constraints}

\paragraph{R1 — Partition.} Every cell belongs to exactly one galaxy:
\[
  \sum_{k \in E_{ij}} x_{ijk} = 1
  \qquad
  \forall\,(i,j)\in\mathcal{C}
\]

\paragraph{R2 — Dot anchor.} Every cell touched by dot $k$ must belong to galaxy $k$:
\[
  x_{ijk} = 1
  \qquad
  \forall\,k\in\{1,\ldots,K\},
  \;
  \forall\,(i,j)\in A^k
\]

\paragraph{R3 — Symmetry.} For each galaxy $k$, a cell and its symmetric image must receive the same assignment:
\[
  x_{ijk} = x_{\sigma_k(i,j),\,k}
  \qquad
  \forall\,k,
  \;
  \forall\,(i,j)\in\mathcal{C}
  \text{ with }
  \sigma_k(i,j)\in\mathcal{C}
\]
If $\sigma_k(i,j)\notin\mathcal{C}$, the variable $x_{ijk}$ is fixed to 0 (ineligibility).

\paragraph{R4 — Connectivity.} Each galaxy must form a 4-connected region. This constraint is enforced via lazy cuts (see Section~\ref{sec:connectivity}) rather than upfront constraints.

\paragraph{Constraint propagation.} Before building the model, we run a propagation pass: any cell $(i,j)$ with $|E_{ij}|=1$ is immediately fixed to its unique eligible galaxy, and this fixation is propagated to the symmetric counterpart, which may in turn reduce other eligible sets. This preprocessing step often eliminates a large fraction of binary variables.

\subsection{Connectivity via Lazy-Constraint Callbacks}
\label{sec:connectivity}

Connectivity (R4) cannot be expressed with a polynomial number of upfront linear constraints. Two standard approaches exist:

\begin{itemize}
  \item \textbf{Flow variables.} Introduce flow variables $f_{(i,j)\to(i',j'),k}$ representing commodity flow from the anchor of galaxy $k$ to each of its cells. Flow conservation forces reachability, but adds $O(n\cdot m\cdot K)$ variables and constraints upfront, which becomes prohibitive for large $K$.

  \item \textbf{Lazy-constraint callback (used here).} Constraints R1--R3 are encoded upfront. Each time CPLEX finds an integer-feasible solution, a callback verifies connectivity via BFS from each galaxy's anchor. For any disconnected component $S$ of galaxy $k$, the following separator cut is added as a lazy constraint:
  \[
    \sum_{(i,j)\in S} x_{ijk}
    \;+\;
    \sum_{(u,v)\in N(S)} \bigl(1 - x_{uvk}\bigr)
    \;\geq\;
    1
  \]
  where $N(S)$ is the set of grid cells adjacent to $S$ but not contained in $S$. This forces either $S$ to dissolve or some bridge cell from $N(S)$ to join galaxy $k$. CPLEX then rejects the solution and resumes the branch-and-cut process with the new constraint.
\end{itemize}

The callback approach keeps the model compact and adds cuts only when necessary, which is critical given the large number of galaxies $K$ in bigger instances.

\subsection{Instance Generation}

Galaxies instances cannot be generated by sampling clue values (as in Mosaic) or by sampling a black-cell pattern and verifying connectivity (as in Range), because the constraint web---partition + 180° symmetry + connectivity + one anchor per region---is too tight for rejection sampling to terminate. We therefore generate instances by \emph{construction}, building a valid partition first and emitting the dot positions afterwards.

The procedure grows symmetric regions one at a time:
\begin{enumerate}
  \item Pick a random unassigned grid cell as the seed for the next region.
  \item Enumerate candidate dot positions touching that seed: its centre, the four edges to neighbouring cells, and the four corners. Each candidate is a doubled-coordinate pair $(d_r, d_c)$.
  \item Try the candidates in random order. A candidate is accepted if all its anchor cells $A^k$ (computed by \texttt{cells\_touched\_by\_dot}) are still unassigned. Mark them as belonging to the new region.
  \item \emph{Symmetric pair growth.} While progress is being made, look at every cell on the boundary of the region. For each free boundary cell $(c_i, c_j)$, compute its symmetric image $\sigma_k(c_i, c_j)$ about the new dot. If both the cell and its image are free (or coincide on a self-symmetric cell), assign both to the region. This ensures R3 holds at every step.
  \item If no candidate dot can host a region around the seed, fall back to a single-cell region centred on the seed itself.
  \item Repeat until every cell is assigned.
\end{enumerate}
Because the procedure only ever attaches cells together with their symmetric counterparts to a connected region, the produced instance satisfies all four rules by construction. The dot positions of the resulting partition are exactly the instance to publish; the partition itself is one of its valid solutions.

Datasets are generated for sizes $4{\times}4$, $5{\times}5$, $6{\times}6$, $7{\times}7$, $8{\times}8$, and $10{\times}10$, with three instances per size.

\subsection{Heuristic Solver}

The heuristic provides a warm start for CPLEX by producing a possibly partial feasible assignment without invoking the ILP solver. It proceeds in three phases:

\begin{enumerate}
  \item \textbf{Propagation seed.} All cells with $|E_{ij}|=1$ (a single eligible galaxy after constraint propagation) are immediately assigned. Symmetric counterparts are assigned simultaneously to maintain R3.

  \item \textbf{BFS frontier expansion.} Each galaxy grows outward from its already assigned cells, assigning unassigned neighbours together with their symmetric counterparts whenever possible.

  \item \textbf{Final sweep.} Any remaining unassigned cells are greedily assigned to the first eligible galaxy for which both the cell and its symmetric image are still free.
\end{enumerate}

When the heuristic finds a fully feasible assignment, it is fed to CPLEX as a MIP start via \texttt{set\_start\_value}, significantly reducing the time required to find the first integer-feasible solution. Even partial assignments are passed to CPLEX, since incomplete MIP starts are also accepted.

\subsection{Results}

The dataset comprises 25 instances: 20 generated by the procedure above (three per size from $4{\times}4$ to $10{\times}10$, plus two extra $15{\times}15$) and the five hand-crafted instances used during development. All experiments use CPLEX with a 120-second time limit per instance, the lazy-constraint callback enabled (with the symmetry-strengthened cut), and the heuristic warm start.

CPLEX finds a feasible partition on \textbf{every} instance. The aggregate ``mean'' column dramatically hides the bimodal regime at $10 \times 10$, which the median exposes: mean $0.64$\,s vs.\ median $0.014$\,s. The four times are $0.003, 0.004, 0.014, 2.54$\,s---three orders of magnitude apart, with two ``easy'' solves and two ``hard'' ones. Inspecting the instances reveals a clear pattern: the slow ones have \emph{fewer galaxies} (9 and 11) than the fast ones (12 and 14). Counter-intuitively, fewer galaxies makes the problem harder, because anchor cells are the only directly fixed variables; a sparser anchor set leaves larger regions to be discovered by branch-and-bound, with longer connectivity chains and weaker symmetry constraints per region. The $15 \times 15$ instances span a similar range (median $0.093$\,s, max $0.504$\,s) and confirm the same pattern: the densely-anchored hand-crafted $15 \times 15$ (52 galaxies) solves in $0.5$\,s, while the more sparsely-dotted generated $15 \times 15$ instances are noticeably faster.

The heuristic, which is propagation-only with no backtracking, exhibits non-monotone success across grid sizes (4/4, 1/4, 2/3, 1/4, 0/3, 2/4, 1/3 for sizes $4 \times 4 \ldots 15 \times 15$ respectively). This further reinforces the structural-difficulty observation: the determining factor is not size but the depth to which the eligibility-set propagation can collapse cells to a single galaxy before greedy assignment takes over. On $4 \times 4$ instances the propagation pass is sufficient by itself; from $5 \times 5$ onward it depends on the dot configuration. Even when the heuristic returns an incomplete assignment, \texttt{cplexSolve} feeds the partial result to CPLEX as a MIP start via \texttt{set\_start\_value}---incomplete starts are accepted---though our ablation (below) finds no measurable speedup on this dataset.

\subsubsection{Callback Activity and Ablations}

We instrumented the callback to count the number of lazy cuts submitted per instance, and ran ablations on the symmetric-cut strengthening (Section~\ref{sec:connectivity}) and the heuristic warm start. Two findings emerged that were not obvious from the model definition alone:

\textbf{Most instances never trigger the callback.} The combination of partition + anchor + symmetry constraints with the perimeter tiebreaker is strong enough on its own that 19 of the 25 instances solve with zero lazy cuts---CPLEX's first integer-feasible candidate is already connected. The callback is only load-bearing on a minority of harder instances.

\textbf{The symmetric-cut strengthening, which we expected to accelerate convergence, does not help on this dataset.} Disabling it halves the number of cuts (as expected: each baseline cut is now solo rather than mirrored) but on no instance produces a measurable speedup, and on a few it is slightly faster without the strengthening. The cut is mathematically valid---$\sigma_k(S)$ is provably also disconnected---but in practice CPLEX rediscovers the mirror configuration quickly enough that pre-emptively forbidding it adds more bookkeeping than it saves. We retain the strengthening in the codebase since the cost is low and it could matter on instances harder than the ones in our dataset, but the report's earlier framing of it as a clear win was overstated.

\textbf{Disabling the heuristic warm start has no consistent measurable effect at these instance sizes.} Solve times shift by tens of microseconds in either direction, well within CPLEX's run-to-run variance. The warm start machinery is in place for instances where CPLEX struggles to find any first integer-feasible candidate, but on this dataset such instances do not exist.
